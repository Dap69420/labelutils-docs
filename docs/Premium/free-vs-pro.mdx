Vektra is free to use for any server. **Starter** adds branding and customization, **Pro** unlocks the full A&R workflow and web dashboard, and **Pro+** adds a hosted white-label Discord bot for labels that want their own bot identity.

<Info>
  Vektra keeps each server's slash command list tier-aware. Free servers see the core commands, Starter servers see Starter tools, and Pro or Pro+ servers see the full workflow after premium is redeemed.
</Info>

## How to buy

Buying happens on the web — no DMs needed.

1. Open [vektra.games/pricing](https://vektra.games/pricing) and pick a plan.
2. Checkout runs on the dashboard at `dashboard.vektra.games/checkout` — log in with Discord.
3. Pay with **USDT / USDC** (Polygon, Base, Ethereum, or BNB) or a supported method.
4. Choose delivery: **activate instantly on a server you admin**, or get a **redeemable coupon**.
5. Redeem a coupon in any server with `/redeem code:<coupon>`.
6. Your receipt is sent to your Discord DMs.

<Tip>
  Crypto payments activate instantly. Other payment methods (gift cards, Robux, Discord Nitro) are verified manually — email `support@dapmedia.tech` or open a ticket in the Discord server.
</Tip>

<Info>
  Coupons can be wrapped as a gift: after buying, create a gift link with an optional password and share it with anyone. See the FAQ.
</Info>

## Release distribution fee

Free servers can still submit release requests for Vektra QC and Labelcaster delivery. On the free tier, Vektra keeps a **10% service fee**, so the label keeps **90%**.

Paid tiers keep **100%** of distribution earnings.

<Info>
  The service fee only applies to release distribution handled through Vektra. It does not affect demo submissions.
</Info>

## Pro features at a glance

- **Dashboard** — review submissions and tickets, submit and track release requests, DM artists, export CSV, and view analytics graphs.
- **A&R tools** — staff notes (`/note`), reviewer assignment (`/reviewer`), shortlists, priority flags, ratings (`/rate`), saved rejection reasons (`/reasons`), weekly digest (`/digest`), and analytics (`/analytics`).
- **Support tickets** — `/ticket_channel`, `/ticket_panel`, `/tickets`, and `/ticket_set`.
- **Storage** — choose a region with `/storage` or connect your own Neon database with `/setup_db`.

## Pro+ white-label hosting

Pro+ servers can connect their own Discord bot application from the dashboard. The custom bot runs as a dedicated worker on the Vektra VPS, uses that server's Vektra setup, and has its own Discord identity and online status.

The Pro+ Bot page stores the bot token encrypted, shows manager status, and provides an invite link from the buyer's bot client ID. If the custom bot is invited to the wrong server, it leaves automatically. Admins can also use `/white_label_status` and `/white_label` from Discord.

<Note>
  The current Pro+ hosting limit is 5 active white-label bots while the service is in controlled beta.
</Note>

## Dashboard

The dashboard uses Discord login and only shows servers where:

- You are a server admin or have Manage Server permission.
- Vektra is installed in that server.
- The server has an active Pro or Pro+ tier for dashboard-only tools.

From the dashboard you can edit branding, panel templates, demo intake, templates, storage, ticket settings, submission statuses, ticket statuses, release requests, post panels, and post custom embeds from the Messages page.

<Warning>
  When posting panels from the dashboard, make sure the bot can view the selected channel and has Send Messages permission there.
</Warning>

## Storage changes

When you change storage region or connect a custom database, Vektra migrates existing submissions, tickets, branding, and Pro settings before switching. Old managed storage is cleaned up after a successful move.

<Warning>
  When premium expires, saved paid settings are kept but inactive. Existing branded panels may remain visible in Discord, but paid workflows stop until the server renews. Pro+ custom bots stop automatically when Pro+ expires.
</Warning>
