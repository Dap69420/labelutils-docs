Every public Vektra slash command, grouped by who uses it. Run `/help` in Discord to see a shorter command list inside your server.

<Info>
  Commands marked **Starter** require Starter, Pro, or Pro+. Commands marked **Pro** require Pro or Pro+. Paid commands are synced per server, so lower-tier servers usually will not see commands they cannot use. Bot-owner-only maintenance commands are intentionally not listed here.
</Info>

## Everyone

| Command | Description |
| --- | --- |
| `/help` | Show the command list and setup steps inside Discord. |
| `/invite` | Show a clickable invite link for adding Vektra to another server. |
| `/premium` | See how to buy Starter, Pro, or Pro+ — or open [vektra.games/pricing](https://vektra.games/pricing). |
| `/pro_status` | Check whether the current server has an active premium tier. |

## Artists

| Command | Description |
| --- | --- |
| `/submit` | Open the demo submission form. |
| `/submission ticket_id:<id>` | Look up one submission. Artists can only view their own submissions; staff can view any submission. |
| `/my_subs` | Show your submissions in the current server. |
| `/my_demos` | Show a longer list of demos you submitted. |
| `/my_stats` | Show your submitted, accepted, rejected, and queued counts. |
| `/leaderboard` | Show top accepted submitters, grouped by Discord user so name changes do not split stats. |

## Server Setup

| Command | Description |
| --- | --- |
| `/start label_name:<name>` | Create managed Vektra storage and set the server's label name. |
| `/setup_staff channel:<channel>` | Set the private staff channel where new submission cards are posted. |
| `/setup` | Check storage, Pro status, branding, staff channel, ticket channel, demo intake, and thread permissions. |
| `/intake open:<true or false> message:<optional>` | Admin: open or close demo submissions for the server. Works on every tier. |
| `/open_submissions` | Admin: open demo submissions. Works on every tier. |
| `/close_submissions message:<optional>` | Admin: close demo submissions and optionally set the message artists see. Works on every tier. |
| `/db_status` | Check which storage is connected. Managed storage shows the region and schema. |
| `/staff_status` | Check which staff channel is connected. |
| `/setup_db` | **Pro**: connect a custom Neon database. |
| `/storage region:<region>` | **Pro**: move managed storage to West US, Europe (UK), or South-East Asia. |

<Note>
  Free and Starter servers use managed storage automatically. Pro and Pro+ servers can move regions or connect a custom database. When storage changes, Vektra migrates existing submissions, tickets, branding, and Pro settings before switching.
</Note>

Pro and Pro+ servers can also edit storage, branding, templates, routing, ticket settings, and panel posting from the dashboard.

## Staff Submissions

| Command | Description |
| --- | --- |
| `/queue` | Show the newest submissions still in queue. |
| `/recent` | Show the newest submissions across all statuses. |
| `/panel` | Open an admin browser with filters, pages, and refresh controls. |
| `/status ticket_id:<id> new_status:<status>` | Update a submission's status. |

Available submission statuses:

- In Queue
- Needs Review
- Shortlisted
- Processed
- Contacted
- Signed
- Approved
- Rejected

Staff submission cards also include **Approve**, **Reject**, and **DM** buttons. Each submission can open a private staff discussion thread so notes, DM replies, and release logs stay attached to the right ticket.

Pro and Pro+ staff can review submissions from the dashboard too. Web approvals and rejections update the submission, DM the artist, and update the Discord staff card for submissions that have stored message references.

<Note>
  DM reply forwarding works when the artist replies directly to the bot's DM message. Attachments are reuploaded into the staff thread when they fit Discord's upload limit; oversized files fall back to temporary Discord links.
</Note>

## Release Requests

| Command | Description |
| --- | --- |
| `/make-release` | Admin: submit a release request for Vektra QC and Labelcaster delivery. Opens a form for release metadata, C/P lines, composers/producers, and file link. |
| `/check-releases` | Admin: show release requests submitted by the current server, including accepted or rejected status and decision reason. |

Required release metadata includes label name, album title, artists, label owner legal name, mapped artist and owner emails, C line, P line, composer/producer legal names, and a Drive or downloadable link.

<Info>
  Discord release requests use the metadata checker for the paragraph field. Dashboard release requests use separate fields and validate required metadata directly.
</Info>

## Pro Support Tickets

| Command | Description |
| --- | --- |
| `/ticket_channel channel:<channel>` | Set the separate private staff channel where ticket cards appear. This cannot be the demo submission staff channel. |
| `/ticket_panel channel:<channel>` | Post the public button panel users click to open tickets. Requires `/ticket_channel` first. |
| `/tickets status:<optional>` | List recent support tickets, optionally filtered by Open, Waiting, Answered, or Resolved. |
| `/ticket_set ticket_id:<id> new_status:<status>` | Update a support ticket to Open, Waiting, Answered, or Resolved. |

Tickets can also be reviewed in the dashboard. Staff can resolve tickets and DM users from the web while keeping the private Discord ticket channel as the staff record.

## Pro Dashboard

The dashboard is not a slash command, but it is part of the Pro and Pro+ workflow.

| Area | What it does |
| --- | --- |
| Home | Shows server overview, recent activity, and daily analytics cards. |
| Submissions | Review demos, change status, approve, reject, DM artists, and export CSV. |
| Tickets | Review support tickets, change status, resolve, and DM users. |
| Releases | Submit release requests and view accepted or rejected status with decision reason. |
| Analytics | View submission and decision trends with graphs. |
| Branding | Edit display name, tagline, embed color, tutorial panel templates, footer, and logo. |
| Messages | Post custom embeds or plain messages to any channel the bot can access. |
| Settings | Edit demo intake, templates, storage region or custom database, ticket channels, and panel posting. |
| Pro+ Bot | Pro+ only: configure a hosted white-label bot token, client ID, status presets, invite link, manager status, and restart requests. |
