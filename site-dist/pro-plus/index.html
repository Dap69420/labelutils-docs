Premium

Pro+

White-label bot hosting for labels that want their own Discord bot identity

Pro+ includes everything in Pro plus white-label bot hosting. A Pro+ server can connect its own Discord bot application so artists and staff interact with that label's own bot identity instead of only the shared Vektra bot.

Info

Pro+ white-label hosting is self-serve from the dashboard. The server still uses Vektra's workflow, storage, commands, panels, and dashboard, but the hosted bot can use the buyer's own Discord bot token and status.

Included features

Pro+ includes everything from Pro:

  • Starter branding and customization
  • Pro A&R workflow tools
  • Pro storage options
  • Pro dashboard access
  • Pro support tickets
  • Pro analytics and exports
  • Release requests and dashboard release tracking

It also adds:

  • A dedicated hosted Discord bot worker for that server
  • Custom bot token supplied by the buyer
  • Custom bot online status from the dashboard
  • A custom invite link based on the buyer's bot client ID
  • Dashboard restart requests for the hosted worker
  • Discord-side hosting controls with /white_label and /white_label_status
  • Automatic shutdown when Pro+ expires or the hosted bot is disabled

What the buyer needs

The buyer creates a Discord application in the Discord Developer Portal and provides:

  • Bot token
  • Bot client ID
  • Desired status type and status text

The bot name, avatar, and profile description are managed in the buyer's Discord Developer Portal. Vektra hosts the bot connection and workflow.

Warning

A Discord bot token is like a password. Only paste tokens from Discord applications you own. If a token is exposed, reset it in the Discord Developer Portal and update it in the dashboard.

Dashboard setup

  1. Buy or redeem Pro+ for the server.
  2. Open vektra.games and log in with Discord.
  3. Choose the Pro+ server.
  4. Open Pro+ Bot.
  5. Paste the custom bot client ID and token.
  6. Choose the status type and status text.
  7. Enable the hosted bot and save.
  8. Use the status presets or Restart hosted bot when changing runtime behavior.
  9. Use Invite custom bot to add that bot to the same server.

The VPS manager checks for changes roughly every 30 seconds. The dashboard will show manager status such as pending_restart, starting, online, stopped, or error.

Discord controls

Pro+ admins can manage the hosted worker from Discord too:

CommandWhat it does
/white_label_statusShows enabled state, token presence, worker status, last seen time, and the invite link.
/white_label enabled:<true or false>Starts or pauses the hosted worker.
/white_label enabled:<true or false> status_type:<type> status_text:<text>Updates the hosted bot status and queues a manager restart.

Token and client ID setup stays in the dashboard so sensitive token entry only happens in one place.

Server lock

Discord's invite screen may let someone choose any server where they have permission to add bots. Vektra still locks each white-label worker to the configured Pro+ server.

If the custom bot is invited to the wrong server, it leaves automatically. On startup, it also checks existing guilds and leaves any server that does not match the configured Pro+ server.

Expiry and removal

When Pro+ expires, the white-label worker stops automatically on the next manager check. The stored configuration remains in the dashboard so it can be reused after renewal.

To remove or stop a custom bot:

  • Disable it from Dashboard -> Pro+ Bot.
  • Or remove premium with the owner-side premium controls.
  • Or stop the Pro+ manager service if all hosted custom bots need to be paused.

Current hosting limit

Vektra currently runs Pro+ hosting as a controlled beta. The default manager limit is 5 active white-label bots on the VPS.

This limit keeps memory usage predictable. It can be adjusted later when hosting capacity increases.

How is this different from Pro branding?

Pro branding customizes:

  • Server-specific messages and embeds
  • Submit panel captions and colors
  • DM templates
  • Footers, success messages, and thumbnails
  • The bot's server nickname where Discord permissions allow it

Pro+ goes further by running a separate Discord bot connection for the buyer. That gives the label its own bot identity, invite identity, and online status while still using the Vektra workflow.
